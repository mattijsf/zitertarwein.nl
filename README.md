# Zit er tarwe in? 🌾

Minimalist website (in Dutch): type a product and instantly see whether it
contains wheat, with source references. Live at **https://zitertarwein.nl**.

If a product is not in the built-in database, the site searches the label
data of [Open Food Facts](https://nl.openfoodfacts.org/) live (with a
source link). If that also comes up empty, the site offers a Google link
with a prefilled query as a last resort.

## Files

React 19 + zustand, built with Vite, strict TypeScript.

| Path                                 | Purpose                                                                                   |
| ------------------------------------ | ----------------------------------------------------------------------------------------- |
| `index.html`                         | Vite entry: meta tags and `#root`                                                         |
| `public/`                            | Static files shipped as-is: icons, `sw.js`, `_headers`, wheat plate                       |
| `src/app/`                           | Page layout: header with product counts, footer                                           |
| `src/features/`                      | One folder per feature: search, result, examples, facts, browse, barcode scanner, install |
| `src/stores/`                        | Shared state (zustand)                                                                    |
| `src/lib/`                           | Pure logic with tests: search, suggestions, Open Food Facts                               |
| `src/lib/rules.json`                 | Shared wheat-detection rules (site and import scripts)                                    |
| `src/data/products.ts`               | Hand-curated product database (~310 products) with status, source                         |
| `src/data/off-products.json`         | Supermarket products with label data (generated, do not edit)                             |
| `src/data/sources.ts`                | The sources the answers point to                                                          |
| `deploy.sh`                          | Build and deploy to Cloudflare                                                            |
| `generate.py`                        | Generates `src/data/off-products.json` from one or more sources                           |
| `sources/`                           | Source modules: `off_parquet.py` (Open Food Facts), `csv_export.py`                       |
| `scripts/build-seo.ts`               | Generates static product pages (`/p/…`), sitemap and robots.txt                           |
| `og-source.html`, `icon-source.html` | Sources for `og-image.png` and the app icons (render, then screenshot)                    |

Adding a product to `src/data/products.ts`:

```ts
{ n: "product name", a: ["alias"], s: "yes" | "no" | "check", i: "explanation (Dutch)", b: "vc-gluten" | "vc-tarwe" | "ncv" | "off" }
```

## Running locally

```bash
pnpm install
pnpm dev     # http://localhost:4173
pnpm check   # lint, formatting, typecheck, tests, escape hatches and unused code (knip)
```

`pnpm install` also installs the git hooks (lefthook):

- **pre-commit**: ESLint with `--fix` and Prettier (organized imports) on the staged files,
  `tsc -b`, and a block on "do not commit" markers
- **pre-push**: lint, format check, typecheck, tests, knip (unused files, exports and
  dependencies) and the escape-hatch ratchet
  (`scripts/check-escape-hatches.ts`: no new `any`, `as` casts or `eslint-disable`)

## Generating product data

`src/data/off-products.json` is generated by `generate.py`; every data source
is a module in `sources/`. Combine sources by listing them — the first source
wins on duplicate names, and CSV sources are included in full:

```bash
pip3 install duckdb
curl -L https://huggingface.co/datasets/openfoodfacts/product-database/resolve/main/food.parquet -o food.parquet
python3 generate.py off=food.parquet
# or with an extra (supermarket) export:
python3 generate.py csv=supermarket-export.csv off=food.parquet
```

CSV format: columns `naam` and `ingredienten` (required) plus optional
`merk`, `barcode` and `sporen` (Dutch column names, matching the exports
this site works with); the delimiter is detected automatically. See
`sources/csv_export.py`. Adding a new source = one module with a
`read(path)` function that returns the shared product format.

From the Open Food Facts export (± 8 GB, ODbL licence) the generator
selects the most popular Dutch products with ingredient information, plus
extra coverage per risk category (sauces, soups, biscuits, sweets, …).
`src/data/off-products.json` is only overwritten on a successful run, and
the browser loads it lazily (own chunk) after the page has rendered.

The detection rules (which words and tags indicate wheat) live in one
place, `src/lib/rules.json`, and are used by both the site and the import
scripts.

All-in-one refresh (download + import + commit + auto-deploy):

```bash
./refresh-data.sh
```

To run it periodically, use a crontab entry such as this one (1st of the
month at 06:00):

```
0 6 1 * * /path/to/zitertarwein.nl/refresh-data.sh >> /tmp/zitertarwein-refresh.log 2>&1
```

## Deploying

Hosting: **Cloudflare Worker** `zitertarwein` (static assets) —
zitertarwein.nl is attached to it as a custom domain. Configuration in
`wrangler.jsonc`.

- **Automatic**: every commit on `main` deploys via the local post-commit hook.
- **Manual**: `./deploy.sh`

The script builds `dist/` with `pnpm build` (Vite, which hashes the asset
file names for cache busting, then `node scripts/build-seo.ts dist`: one
small page per product under `/p/`, an A-Z index, `sitemap.xml` and
`robots.txt` — so search engines can answer "zit er tarwe in …" queries
directly) and runs `npx wrangler deploy`.

### Auto-deploy on a new machine

The hook lives in `.git/hooks/` and does not travel with git. One-time setup:

```bash
npx wrangler login   # approve Cloudflare OAuth in the browser

cat > .git/hooks/post-commit <<'EOF'
#!/bin/sh
# Auto-deploy: every commit on main goes to Cloudflare.
[ "$(git rev-parse --abbrev-ref HEAD)" = "main" ] || exit 0
echo "→ Auto-deploying to Cloudflare…"
sh "$(git rev-parse --show-toplevel)/deploy.sh" 2>&1 | tail -2
EOF
chmod +x .git/hooks/post-commit
```

If the wrangler session ever expires, a fresh `npx wrangler login` is enough.

## Sources

Answers reference a verified source per product:

- [Voedingscentrum — Gluten en het glutenvrij dieet](https://www.voedingscentrum.nl/encyclopedie/gluten-en-het-glutenvrij-dieet.aspx)
- [Voedingscentrum — Tarwe: volkorenmeel en bloem](https://www.voedingscentrum.nl/encyclopedie/tarwe-meel-bloem.aspx)
- [Nederlandse Coeliakie Vereniging — glutenvrij.nl](https://www.glutenvrij.nl/)
- [Open Food Facts](https://nl.openfoodfacts.org/) — label data, also used for the live search
- [NVWA — allergenen op het etiket](https://www.nvwa.nl/onderwerpen/allergenen) — legal basis for the mandatory (bold) wheat mention on labels (EU 1169/2011)
- [MDL Fonds — coeliakie](https://www.mdlfonds.nl/ziekten/coeliakie/)
- [Stichting Voedselallergie — tarweallergie](https://www.voedselallergie.nl/allergenen/tarwe/) — patient organisation, wheat-specific
- [Thuisarts.nl — coeliakie](https://www.thuisarts.nl/coeliakie) — medical information

The site provides general information and is not medical advice.
Wheat-free is not the same as gluten-free: rye and barley also contain
gluten.
